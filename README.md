
# AgriInfluence 🌱

AgriInfluence is an AI-powered agriculture e-commerce platform built for competition use. It helps users browse agricultural products, manage cart and orders, and use an AI advisor for rose disease detection from uploaded images.

## Features

- Home page with product highlights
- Product listing page
- Cart management
- Wishlist
- Orders page
- Track order page
- AI Advisor for rose leaf disease detection
- Admin panel for managing products and orders
- User login and signup
- Responsive navigation bar

## Tech Stack

### Frontend
- Next.js
- React
- Tailwind CSS
- TypeScript

### Backend
- Java
- Spring Boot

### Database
- MySQL

### AI
- TensorFlow / Keras model
- Flask API for prediction
